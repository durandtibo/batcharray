    Utils¶

    batcharray.utils ¶

    Contain utilities shared by the array and nested packages.

    batcharray.utils.NestedArray module-attribute ¶

    NestedArray: TypeAlias = (
    np.ndarray
    | Mapping[Any, "NestedArray"]
    | Sequence["NestedArray"]
)

    An array or a nested structure (dictionary, list, tuple and their subclasses) of arrays.

    batcharray.utils.T module-attribute ¶

    T = TypeVar('T', bound=NestedArray)

    A nested array type: a function of type T -> T returns the same structure as its input.

    batcharray.utils.apply_to_arrays ¶

    apply_to_arrays(
    data: T, fn: Callable[[ndarray], Any]
) -> T

    Apply a function to every array of a nested structure.

    The output has the same structure as the input: the containers (dict, list, tuple and their subclasses) are kept and every array is replaced by the output of the function. This is also the tool to apply a function that the package does not wrap, like a pointwise function.

    Parameters:

    Name Type Description Default
    data T

    The input data. It can be an array or a nested structure of arrays.

    		 required
    fn Callable[[ndarray], Any]

    The function applied to each array.

    		 required

    Returns:

    Type Description
    T

    The data with every array replaced by the output of fn.

    Raises:

    Type Description
    TypeError

    if a leaf of the data is not an array.
    Example 
    >>> import numpy as np
>>> from batcharray.utils import apply_to_arrays
>>> apply_to_arrays({"a": np.array([1.0, 4.0]), "b": [np.array([9.0])]}, np.sqrt)
{'a': array([1., 2.]), 'b': [array([3.])]}

    batcharray.utils.combine_arrays ¶

    combine_arrays(
    items: Sequence[T],
    fn: Callable[[Sequence[ndarray]], Any],
) -> T

    Combine nested structures of arrays that have the same layout.

    The structures are traversed in parallel, and fn receives the arrays found at the same position in every structure. The containers of the output are the ones of the first item: a list and a tuple can be combined (the output has the type of the first item), as can a dictionary and an ordered dictionary.

    Parameters:

    Name Type Description Default
    items Sequence[T]

    The structures to combine. They must have the same layout (same dictionary keys, same sequence lengths).

    		 required
    fn Callable[[Sequence[ndarray]], Any]

    The function used to combine the arrays found at the same position.

    		 required

    Returns:

    Type Description
    T

    The combined structure.

    Raises:

    Type Description
    TypeError

    if a leaf of the items is not an array.
    ValueError

    if no item is given, if the items have different layouts (dictionary keys, sequence lengths) or if a mapping is combined with a sequence.
    Example 
    >>> import numpy as np
>>> from batcharray.utils import combine_arrays
>>> combine_arrays(
...     [{"a": np.array([1])}, {"a": np.array([2])}],
...     np.concatenate,
... )
{'a': array([1, 2])}

    batcharray.utils.get_namespace ¶

    get_namespace(*arrays: ndarray) -> ModuleType

    Return the NumPy namespace that implements the operations of some arrays.

    A subclass of numpy.ma.MaskedArray is dispatched as a masked array. A subclass of numpy.ndarray is a plain array. When several arrays are given, one masked array in any position is enough to choose numpy.ma, because numpy drops the mask of the masked arrays that are not first.

    Parameters:

    Name Type Description Default
    *arrays ndarray

    The input arrays.

    		 ()

    Returns:

    Type Description
    ModuleType

    numpy.ma if at least one array is a masked array, otherwise numpy.
    Example 
    >>> import numpy as np
>>> from batcharray.utils import get_namespace
>>> get_namespace(np.ones((2, 3))).__name__
'numpy'
>>> get_namespace(np.ma.ones((2, 3))).__name__
'numpy.ma'
>>> get_namespace(np.ones((2, 3)), np.ma.ones((2, 3))).__name__
'numpy.ma'

    batcharray.utils.get_size ¶

    get_size(data: NestedArray, axis: int) -> int

    Return the size of the axis shared by all the arrays.

    Parameters:

    Name Type Description Default
    data NestedArray

    The input data. It can be an array or a nested structure of arrays.

    		 required
    axis int

    The axis. BATCH_AXIS is the batch axis and SEQ_AXIS is the sequence axis.

    		 required

    Returns:

    Type Description
    int

    The size of the axis.

    Raises:

    Type Description
    TypeError

    if a leaf of the data is not an array.
    ValueError

    if the data has no array, if an array has fewer dimensions than needed, or if the arrays have different sizes along the axis.
    Example 
    >>> import numpy as np
>>> from batcharray.constants import BATCH_AXIS
>>> from batcharray.utils import get_size
>>> get_size({"a": np.ones((2, 3)), "b": np.zeros(2)}, axis=BATCH_AXIS)
2

    batcharray.utils.split_arrays ¶

    split_arrays(
    data: T,
    fn: Callable[[ndarray], Sequence[ndarray]],
    *,
    axis: int,
) -> list[T]

    Split a nested structure of arrays into a list of structures.

    Parameters:

    Name Type Description Default
    data T

    The input data. It can be an array or a nested structure of arrays.

    		 required
    fn Callable[[ndarray], Sequence[ndarray]]

    The function used to split each array into pieces.

    		 required
    axis int

    The axis along which fn splits the arrays. All the arrays must have the same size along this axis, otherwise the pieces of different arrays are not aligned.

    		 required

    Returns:

    Type Description
    list[T]

    A list of structures with the same structure as the input. The i-th structure contains the i-th piece of each array.

    Raises:

    Type Description
    TypeError

    if a leaf of the data is not an array.
    ValueError

    if the data has no array, or if the arrays have different sizes along the axis.
    Example 
    >>> import numpy as np
>>> from batcharray.utils import split_arrays
>>> split_arrays(
...     {"a": np.arange(4), "b": [np.arange(4) + 10]},
...     lambda array: np.array_split(array, 2),
...     axis=0,
... )
[{'a': array([0, 1]), 'b': [array([10, 11])]},
 {'a': array([2, 3]), 'b': [array([12, 13])]}]
